## 휴대폰에서 처음 한 번

1. 휴대폰 Chrome(안드로이드) / Safari(아이폰)에서 위 주소 열기
2. **홈 화면에 추가**: Chrome 메뉴 ⋮ → *홈 화면에 추가* / Safari 공유 □↑ → *홈 화면에 추가*
   → "출장등록" 아이콘으로 앱처럼 열리고, 인터넷이 약해도 화면은 열립니다(오프라인 캐시).

## 현장 사용 팁

- **가로로 들고 촬영**하면 16:9 화면을 꽉 채웁니다. 셀카는 [셀카] 또는 촬영 화면의 [셀카] 전환.
- 코멘트 상자는 **지우기 전까지 유지** → 같은 장소는 코멘트 한 번 쓰고 연속 촬영.
- 로밍이 끊겨도 촬영·작성은 계속 됩니다(기기에 임시 저장). 연결되면 **[저장]**으로 Supabase에 올리세요.
- 갤러리 사진은 사진에 위치정보가 있어야 자동으로 들어갑니다.
  - 아이폰: 설정 → 개인정보 보호 → 위치 서비스 → 카메라 → *앱을 사용하는 동안*
  - 위치가 없는 사진은 사진 카드의 **[현재 위치로]**
- PC에서는 탐색기의 사진을 사진등록 화면에 **끌어다 놓으면** 바로 추가됩니다.
